# 配置与隐私

## 两层设置

手机保存服务地址、主题和高速传输偏好；服务访问口令按服务地址绑定，HarmonyOS 使用 Asset Store，iOS 使用 Keychain，Android 使用 Keystore 加密保存。旧版鸿蒙调试预配置仅在 Debug 首次启动时迁移，成功后删除该私有文件。公开源码构建不包含个人地址、口令或供应商密钥。

服务端每个部署只有一份配置。授权用户可通过 `/api/settings` 读取非密钥参数及密钥是否已配置，通过 POST 保存修改。配置文件位于数据目录 `provider-settings.json`，权限 0600，原子写入；当前是私有文件保护，不是加密数据库。部署访问口令等同管理权限，不应共享给不可信用户。

优先级：App 保存的服务设置 → 环境变量 → 通用默认值。保存时将当前有效配置写成快照。正在执行的阶段使用启动时的配置，下一阶段读取新设置。每次保存携带 revision，冲突返回 409，重新读取后再修改。

密码框为空表示保留；显式选择「清除已保存密钥」才删除。更换 ASR 或 LLM 接口地址时必须填写对应的新密钥，或明确清除旧密钥；禁止把原来的密钥自动发往新地址。接口拒绝 HTTP、带用户名密码、查询参数或片段的服务地址；不跟随供应商重定向。

## ASR

- NVIDIA Parakeet 中文：`ASR_PROVIDER=nvidia_parakeet`，使用 `NVIDIA_API_KEY`，默认语言 `zh-CN`。
- NVIDIA Whisper：`ASR_PROVIDER=nvidia_whisper`，使用同类 NVIDIA API Key，完整录音分段上限 60 秒。
- OpenAI 兼容：`ASR_PROVIDER=openai_compatible`，配置 `ASR_BASE_URL`、`ASR_MODEL`、`ASR_API_KEY`；以 multipart WAV 调用 `/audio/transcriptions`。`ASR_RESPONSE_FORMAT` 为 `verbose_json` 或 `json`，返回必须有 text。没有时间戳、说话人就保留 null，不推测补全。供应商返回格式、额度、模型兼容性需实测。

高级参数：`ASR_CHUNK_SECONDS` 10–300 秒，`NVIDIA_TIMEOUT_SECONDS` 10–3600 秒，`NVIDIA_MAX_SPEAKERS` 1–8，`NVIDIA_SPEAKER_ZERO_POLICY` 默认 unknown。热词只传递给支持该参数的 NVIDIA 接口；当前未将热词映射到兼容 ASR。

## LLM

接口地址包含 API 前缀，例如 `https://api.example.com/v1`，调用路径追加 `/chat/completions`。设置中提供自定义、OpenAI、NVIDIA 的地址选择，模型 ID 和密钥自行填写，不预设付费模型。模型需接受 temperature、messages 和 `response_format=json_object` 并返回结构化结果。

地址依据官方接口：[OpenAI Chat Completions](https://platform.openai.com/docs/api-reference/chat)、[NVIDIA Chat Completions](https://docs.api.nvidia.com/nim/reference/google-gemma-7b-infer)。接口预设只帮助填写地址，不表示所有模型均兼容。

## 飞书

- **服务器 CLI**：保持服务器既有用户登录，配置 CLI profile（可留空）及预期 Open ID，写入前核对身份。
- **用户令牌**：填写 user_access_token 与预期 Open ID，令牌过期需更新，当前未实现 OAuth 自动刷新。
- **应用凭据**：填写 App ID、App Secret，通过[官方 tenant_access_token 接口](https://open.feishu.cn/document/server-docs/authentication-management/access-token/tenant_access_token_internal)获取应用身份令牌。需自己配置开放平台文档权限，将目标文件夹授权给应用。这不是个人用户令牌。

切换身份方式后需重新勾选确认。文档域名可填写自己的组织域名；文件夹 Token 可选。没有确认身份时写入阶段明确阻断。

## 运维与恢复

`PUBLIC_ORIGIN`、监听地址、数据目录、磁盘保留空间、服务访问口令、HTTPS 证书和备份目的地属于部署引导参数，在服务启动或部署配置中管理，避免运行中误改导致自己无法连接。App 可设置业务参数和自己的服务连接。

`AUTO_PIPELINE=1` 时完整上传后继续转写、总结和飞书；默认关闭，先核实供应商和身份。设置保存成功不等于服务认证或真实任务通过。

录音备份不含 `provider-settings.json`、access-token 和 `.env`。请单独加密保存凭据；不要将凭据备份放入源码副本。恢复后可重新填写服务配置。不要把个人数据、签名、调试包、日志或真实录音截图上传开源仓库。

## 标题、日期与飞书排版

D3200 文件编号按设备时间解析为开始录制时间，云端单独保存 `recorded_at`，不与上传时间混淆；时间取决于设备时钟准确性。未知来源保留未知。App 使用手机当地时间，飞书使用设置中的 `DOCUMENT_TIMEZONE`，默认 Asia/Shanghai。

LLM 总结完成后生成简洁标题，更新录音卡片及文档标题。文档使用真实标题块，先显示基本信息，再显示摘要、结论、待办、转写与识别说明；空栏目省略，连续未识别时段合并。正文和原始响应保留在服务器。已发布文档不会在后台盲目覆盖；本次旧文档升级执行了逐篇备份、原内容核对、保持 URL 的重排版与回读验证。

点击已发布的录音卡片会使用[飞书官方 AppLink](https://open.feishu.cn/document/uAjLw4CM/uYjL24iN/applink-protocol/supported-protocol/open-docs)调起文档，系统可能要求首次确认。回听入口通过鉴权读取服务器音频，不下载永久副本。未生成文档时进入处理状态。

完整文件云端核验通过后删除手机音频缓存；同一来源的传输临时文件通过来源清单关联清理。实时分段收到一致的云端回执后，先持久化清理任务再删除，重启可继续清理；未确认保存的音频继续保留。设备原始录音不会删除。


## 实时延迟与自动上传

- 实时切片在「设置 → 语音转写」选择 2 / 5 / 10 / 20 秒，默认 5 秒，本机自动保存，下次接收生效。切片长度不等于出字延迟，仍叠加上传、排队和识别时间；短切片可能拆断词句，最终全文以完整录音处理结果为准。
- 后端为实时片段单独运行一个串行处理线程，不受长录音任务阻塞。既有 20 秒会话保持原窗口，恢复上传不会改变旧片段编号或偏移。
- 「录音」页提供「连接后自动上传」开关（默认开启）和「高速传输」按钮。自动上传遵循设置中的高速 Wi-Fi 偏好；按钮明确采用高速 Wi-Fi。系统网络授权仍需要允许。
- 连接成功及前台已连接期间定期检查完整录音，按列表顺序同步。设备正在录音时暂停完整文件同步；停止录音后再检查上传。录音豆目前录音期间会阻止完整下载。
- 设备身份由加密握手后读取的设备序列号生成 SHA-256 稳定编号，蓝牙地址只用于连接；序列号缺失或异常时停止同步，不回退到蓝牙地址。
- 老版本蓝牙地址归档首次迁移时，需要读取完整文件，按录音编号、大小、MIME 与 SHA-256 比对并回读验证云端原件。匹配后建立该录音的稳定身份关联，保留录音 ID 和飞书 URL；后续连接直接跳过。不会仅凭时间戳建立整台设备的地址别名，也不自动删除已经存在的重复文档。
- 旧地址的未完成批次清单保存在手机 legacy-batch 文件中，缓存继续保留。升级后先重新连接设备，以有效序列号重新规划；不直接按旧地址继续创建归档。
- 高速传输整批只连接一次录音豆 Wi-Fi，连续下载所有待传文件，再关闭热点、恢复互联网并顺序上传。系统可能分别提示信任设备热点和继续使用无互联网的 WLAN；不会为每条录音重复切换网络。
- 传输卡显示当前阶段、第几条/总条数、已传/总大小和 B/s、KB/s、MB/s；下载速度是音频接收与解密后的有效处理速率，上传速度来自 HTTP 实际发送字节。停顿时速度归零，100% 发送后仍需等待云端完整性校验。
- 批次清单持久化；重启或中断后点击「继续传输」。全部已缓存时直接恢复上传，无需连接录音豆。云端已校验的分片跳过；只有一致的完整回执才清理手机缓存，设备原件保留。
- 上传会话、分片与完成请求遇到指定短暂网络错误时最多重试两次，间隔 1/2 秒，暂停会阻止后续请求。不重试鉴权、证书或完整性错误；持续失败停止本轮并保留音频，用户点击继续。
- App 在前台维持连接与传输，系统退出或回收进程后不承诺手机继续下载。云端已收到的任务独立继续。

飞书「待办事项」使用原生可勾选块（checkbox / todo），责任人、日期、原文依据保留在其后；只有原始总结里的明确行动项会转为待办。没有行动项不创建空待办，普通发布重试保留用户勾选状态。


## 全局设备状态与合并录音页

App 底部保留「录音、实时、设置」三个标签。固定顶部栏在所有标签和录音详情中展示连接、录音/传输状态、录音豆与充电盒电量、充电状态。断开连接不沿用旧电量，未取得字段显示未知；电量使用设备档位对应的近似值。点击「连接 / 管理」回到录音页展开设备操作和诊断。

「录音」页统一提供设备扫描连接、自动上传、高速批量传输、待同步设备文件、云端录音和回听。设备连接面板默认收起，连接成功自动收起；待同步文件与已归档记录按同一设备标识和源 ID 对照，传输进行时集中展示一个进度卡。实时页的连接入口和未配置服务时的跳转已适配三标签结构。
