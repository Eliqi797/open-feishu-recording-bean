# 飞书录音豆：官方 App 与 Open 飞书录音豆怎么选

Open 飞书录音豆是非官方互操作项目，面向愿意自行部署的单人用户。下表比较的是**使用方式和维护责任**，不是对官方当前功能、价格或服务条款的断言；官方产品信息请以当期官方说明为准。

| 考虑的问题 | 官方 App 路线 | Open 飞书录音豆路线 |
| --- | --- | --- |
| 开始使用 | 按厂商提供的安装和账号流程。 | 自行构建并签名原生 App，部署 Python 服务与 HTTPS。 |
| 音频保存位置 | 取决于官方产品与用户设置。 | 同步到使用者自己的服务器；仍需自己做备份和恢复验证。 |
| 转写与总结 | 以当期官方可用能力和条款为准。 | 使用自己配置的 NVIDIA NIM 或兼容 ASR、兼容 LLM。 |
| 飞书文档 | 以官方产品当前提供的工作流为准。 | 使用自己授权的用户令牌、应用凭据或服务器 lark-cli 模式。 |
| 成本与维护 | 依赖官方当期定价和支持方式。 | 项目代码本身不含订阅，但服务器、API、域名及维护由使用者承担。 |
| 验证责任 | 按官方支持渠道处理。 | 使用者需按[状态清单](STATUS_AUDIT.md)验证设备、长录音、供应商、飞书和备份。 |

如果希望尽量少安装和维护，先评估官方 App。如果需要控制音频保存位置、ASR/LLM 选择和文档处理链路，并能承担部署与验收工作，再考虑 Open 飞书录音豆。它目前不是官方服务的完整替代品；[普通用户指南](USER_GUIDE.md)建议先用一条已结束的短录音逐段验证。
