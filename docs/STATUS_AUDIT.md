# 项目状态与验收边界

本页区分**源码实现、自动测试和真实环境验收**。公开仓库不包含个人录音、生产配置、飞书文档、供应商原始响应或私有测试日志；它们不能被当作可复现的公开测试证据。

| 范围 | 当前可确认的内容 | 仍需使用者在自己的环境验证 |
| --- | --- | --- |
| 服务端 | 上传会话、分片续传、大小和 SHA-256 核验、处理阶段状态、受保护回听与配置接口有自动测试。 | HTTPS、磁盘、独立备份恢复、实际 ASR/LLM/飞书额度与授权。 |
| HarmonyOS | 普通 App、设备协议和高速传输路径已实现；共享协议有测试。 | 目标手机及 D3200 固件上的连接、热点授权、长文件与中断恢复。 |
| Android | BLE、热点、云端上传和界面代码已实现，构建与单元检查见 README。 | 自己手机的系统授权、后台限制、多文件连续传输与长录音。 |
| iOS | CoreBluetooth、手动入网、上传和 SwiftUI 界面已实现；免费个人团队使用手动热点模式。 | 个人签名、热点切换后重连、锁屏行为、长录音和系统版本差异。 |
| ASR 与纪要 | 支持 NVIDIA NIM 或兼容接口；说话人、总结和飞书分别记录阶段状态。 | 多人、重叠发言、术语、时间戳、内容准确性及本人飞书文档回读。独立 Sortformer 未接入。 |

真实验收请按[用户指南](USER_GUIDE.md)使用一条已结束的短录音开始，保留设备原文件；随后单独验证长录音、断网和备份恢复。`/healthz`、构建成功或阶段 `completed` 都不能代替音频内容和文档内容的人工核对。平台细节见[跨平台客户端](CROSS_PLATFORM.md)，接口语义见[API](API.md)。
